# What's changed

This page lists the changes to the Queens Hazard Ranking report that a reader would notice, newest first, including corrections when we published something wrong.

- **History begins:** 2026-09-08, the day the report was first published. Dates are the day each version went up on the site, in New York time. Corrections made before this date may be missing.
- **Data refresh:** none. The figures come from NYC Open Data and City reports as they stood when the report was last built, and they do not update on their own.

To report a bug in the report, or to ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/queens-hazard-ranking/issues).

## 2026-11-12: A page that lists what changed in the report

- **Tags:** Site
- **What changed:** This page is new. It lists each version of the report and any correction, newest first. The report links to it from its footer the next time the report is rebuilt.
- **More detail:** [The file this page is built from](https://github.com/BetaNYC/queens-hazard-ranking/blob/main/WHATS-CHANGED.md)

## 2026-09-10: A first ranking of hazards for each Queens district

- **Tags:** Site, Data
- **What changed:** The report now scores five hazards from 1 to 5 for each Queens district (Community District Tabulation Area) and puts them in order, with a map or chart for each hazard. Heavy rain and hazmat are now scored in fifths, replacing the first version's table of citywide percentiles for stormwater flooding. The report calls this an initial ranking and says the remaining hazards would be placed using feedback from subject matter experts.
- **More detail:** [The commit](https://github.com/BetaNYC/queens-hazard-ranking/commit/b723040) · [Same-day edits](https://github.com/BetaNYC/queens-hazard-ranking/commits/main/?since=2026-09-10&until=2026-09-11)

## 2026-09-08: The report is published

- **Tags:** Site, Data
- **What changed:** The first version regroups the ten hazards in the City's 2024 Jurisdictional Risk Assessment into eight hazards for the Queens Resource Map, lists the data available to compare Queens districts on each one, and shows how much of each district floods in heavy rain.
- **More detail:** [The commit](https://github.com/BetaNYC/queens-hazard-ranking/commit/25899a5)
